
# Quote Generator with History

## Description
This application fetches random quotes from an external API and displays them to users. Every fetched quote is stored as quote history.

## Features
- Random quote generation
- API integration
- Quote history storage
- Beautiful UI

## Technologies Used
- Node.js
- Express.js
- Axios
- EJS
- HTML
- CSS

## Run Project

npm install
node server.js

Open:
http://localhost:3000
